## [0.0.1] - 2026-08-15

### Added

- Standalone plugin manifest parsing and validation.
- Plugin registration, loading, lifecycle, and method dispatch.
- Session and application host contracts.
- Owner-isolated plugin data, cache, temporary, and legacy storage paths.
- Revocable credential capability facade.
- TypeScript declarations and a dedicated manifest export.
